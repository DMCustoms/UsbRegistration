# UsbRegistration

Небольшое приложение с графическим интерфейсом, позволяющее производить регистрацию используемых в организации флэш-накопителей сотрудником IT-отдела либо сотрудником службы безопасности. 

Регистрация производится по данным об устройстве (серийный номер, название, VID/PID, номер защитной марки) и данным о сотруднике (фамилия, имя, отчество, структурное подразделение).

## Функции

Приложение реализует следующие функции:
- Автоматическое создание файла базы данных формата SQLite, либо подключение ранее используемого файла, проверка базы данных на валидность;
- Обнаружение подключенных к компьютеру USB-устройств, фильтрация списка обнаруженных устройств с возможностью вывода только USB-накопителей;
- Регистрация устройства путем создания записи в базе данных, автозаполнение полей формы регистрации, отображающих информацию, идентифицирующую устройство;
- Проверка регистрации подключенного устройства;
- Поиск по базе данных, изменение и удаление информации о зарегистрированных устройствах;
- Экспорт серийных номеров зарегистрированных устройств для дальнейшего использования сотрудниками службы безопасности, например, для создания "белого списка" разрешенных в организации флэш-накопителей средствами DLP-системы.

### Запуск

Для запуска приложения требуется Java SE 22.

- Клонируйте репозиторий и перейдите в папку проекта:
```
git clone https://github.com/DMCustoms/UsbRegistration.git
```
```
cd UsbRegistration
```
- Выполните сборку: 
```
mvn package
```
- Перейдите в директорию target и выполните запуск приложения:
```
cd target/
``` 
```
java -jar UsbRegistration-0.1-jar-with-dependencies.jar
```
### Использование

Основные функции приложения доступны после создания файла базы данных: 
`Файл` -> `Создать файл БД`. Выберите место сохранения файла и назовите его произвольным именем. Кнопка `Обнаружить` выводит подключенные USB-устройства, при нажатии `Регистрировать` открывается форма регистрации. Открыть базу данных можно следующим образом: `Поиск` -> `Открыть БД`.
